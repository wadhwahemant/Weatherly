# 🌤️ Weatherly

### A clearer view of your day.

Weatherly is a modern, responsive weather web application designed to provide users with weather information for their preferred locations. It aims to make checking weather conditions simple, intuitive, and visually appealing.

Built using HTML, CSS, and Vanilla JavaScript, this project is also a hands-on journey into frontend development, API integration, and real-world JavaScript concepts.

---

## 🚀 Project Overview

Weatherly aims to provide users with an easy way to explore weather conditions across different locations.

Users will be able to search for a city manually or use their current location to access relevant weather information.

The primary goal is to create a clean and user-friendly weather dashboard while practising core JavaScript concepts.

## ✨ Planned Features

- 🌍 Search weather by city name.
- 📍 Detect current location using browser geolocation.
- 🌡️ Display current temperature.
- 💧 Show humidity levels.
- 💨 Display wind speed.
- ☁️ Show weather conditions.
- 📅 Display current date and day.
- 🌤️ Provide hourly and weekly forecasts.
- 🌙 Dark and light mode.
- ⭐ Save favourite locations.
- 🔄 Switch between Celsius and Fahrenheit.
- 📱 Responsive design for mobile and desktop devices.

*Features will be implemented progressively.*

## 🌐 Weather API

Weatherly plans to use the Open-Meteo API to retrieve weather information.

Open-Meteo provides weather forecasts and current weather information without requiring an API key for non-commercial use.

**API Documentation:** https://open-meteo.com/en/docs

**Geocoding API:** https://open-meteo.com/en/docs/geocoding-api

The application will use the Geocoding API to convert city names into geographical coordinates (latitude and longitude), which will then be used to retrieve weather information.

## 💻 Getting Started

Follow these steps to run Weatherly locally.

### 1. Clone the repository

```bash
git clone https://github.com/wadhwahemant/Weatherly.git
```

### 2. Navigate to the project directory

```bash
cd Weatherly
```

### 3. Open the project

Open the folder in Visual Studio Code.

### 4. Run the application

Use the Live Server extension in VS Code to launch `index.html` in your browser.
